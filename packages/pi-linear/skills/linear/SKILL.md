# Linear

- Use `linear_issue` for one issue; it includes description and comments.
- Use `linear_states` before transitioning an issue so the target state is valid.
- `linear_comment` and `linear_transition` ask for confirmation.
- Authentication: run `/linear-login` interactively or set `LINEAR_API_KEY`/`LINEAR_TOKEN`.
